# 稳定决策

- **真实 JSONL schema**：Claude tool_result 在 `type:"user"` 消息，内层 content 为字符串；`type:"thinking"` 需静默过滤（不出现在 chat.log）。
- **`capture_status` 生命周期**：`"pending"`（init_meta）→ `"ok"` 或 `"warning"`（collect 后）；timeout 路径也必须调 collect/diagnose。
- **cwd_hash**：先 `realpath` → 再 `sed`；mock-claude 与 adapter 保持同一实现（单一来源）。
- **5xx 分类**：word-boundary 正则；api error/internal server/service unavailable 明确字符串。
- **ARG_MAX 防护**：prompt >900KB 明确报错，不静默截断。
- 其余决策继承自 T1 和 T2 handoff.md「稳定决策」段。
