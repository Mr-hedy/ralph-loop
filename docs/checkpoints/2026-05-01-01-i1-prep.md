# 稳定决策

- HUMAN-N 是任务类型之一，但**必须人工介入**（在 main agent 对话中协作完成）；ralph oneshot 内 agent 不可勾不可执行（PROMPT.md 强约束 + 工具层 hardcode 双重保险）。
- 任务前缀必须全大写英文（启动校验快速失败，exit 1）；无前缀任务向后兼容视为 DEV。
- iteration 完成动作 = `cp .ralph/TASKS.md docs/requirements/<module>/I<N>-FINAL-TASK.md`；归档不可变。
- 取消 SUMMARY.md（之前讨论过的设计），信息已分布在 TASKS.md（任务事实）+ status.json（机器可读）+ 终端打印 + exit-message.txt（接力提示）。
- Provider 配置目录用中立 `RALPH_PROVIDER_CONFIG_DIR` 抽象，由 adapter 翻译；不让用户在 .env 直接写 provider 原生变量名（屏蔽 provider 差异）。
- 退出原因新增 `blocked_by_human`（exit code 7）；exit code 4 仍属 `max_iterations`（沿用 v0.1 约定，不变更）。
- T→I 命名迁移走"保留历史方案"：T0-T7 保留作为 v0.1 历史 phase 命名，新阶段统一用 I 前缀，dogfood 是 I1（不延续 T0-T7 编号）。
