# 核心 Bug 修复（T6.7.1）

**根因**：`ralph_worktree_fingerprint()` 使用 `git status -z | tr '\0' '\n'` 输出包含 `.ralph/runs/iter-NNN/` 未追踪目录。每轮 ralph 新建一个 iter 目录，导致指纹每轮都变，stagnation 永远不累加。

**修复**：
- `git ls-files -s` 输出：用 `grep -v $'\t\.ralph/'` 过滤 `.ralph/` 追踪文件。
- `git status -z` 输出：用 `grep -v '\.ralph/'` 过滤所有 `.ralph/` 行。

**单元测试验证**：
```
fp1 = fp2（新增 .ralph/runs/iter-001/ 后指纹不变）PASS
fp2 ≠ fp3（workspace 真实改动后指纹变化）PASS
```
