## v0.1 能力清单

### 核心循环

- `ralph run`：fresh oneshot loop，每轮调 provider CLI，产生 `.ralph/runs/<run_id>/iterations/iter-NNN/`
- TASKS.md 解析：顶层 `- [ ]` / `- [x]`，子 bullet 透传给 agent 不进解析
- done 检测：全部 `[x]` 时 `exit_reason=done`
- stagnation 检测：per-iter fingerprint（`git ls-files -s` + `git status -z`，过滤 `.ralph/`），连续 N 轮无变化 → `exit_reason=stagnated`
- max_iter 兜底：`--max-iter=N`（0=无限）→ `exit_reason=max_iterations`
- timeout 兜底：`--timeout=SEC`（0=无限）→ `exit_reason=timeout`（SIGTERM，exit_code=143）
- lock：`--already_running` 防并发
- changed_files 双字段：`changed_files_iter`（本轮）+ `changed_files_total`（累计）

### Provider

- Claude adapter：`claude -p ... --session-id ... --dangerously-skip-permissions --output-format json`；`--effort low/medium/high/xhigh/max` 直通；none/空不拼
- Fake adapter：集成测试专用
- session capture：stdout JSON → `.claude/projects/<cwd_hash>/<session_id>.jsonl`；fallback mtime 扫描

### 部署单元

- `cp -r .ralph/ <workspace>/.ralph/` 一次性带走 bin/ + lib/ + PROMPT.md + TASKS.md（REQ-017 SC-017-1）
- `.ralph/.env` 支持 `RALPH_PROVIDER / RALPH_EFFORT / RALPH_MAX_ITER / RALPH_TIMEOUT / RALPH_STAGNATION_LIMIT / RALPH_MODEL`

### 使用指南

- `README.md ## 快速开始`：前置依赖 / 部署 / 配置 / .gitignore / 首跑 / 结果查看 / 退出原因速查 / v0.1 行为说明
