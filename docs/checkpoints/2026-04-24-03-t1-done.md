# 核心变更

- **T1 全量实现**：按 task.md 9 步顺序完成 common.sh → tasks.sh → session.sh → adapter-fake.sh → run.sh → ralph bin → integration-test.sh → check.sh。
- **两轮 adversarial review，累计修复 9 个问题**：
  - macOS 兼容性（4 个）：`flock` CLI 不可用 → noclobber + PID 文件锁；`printf '- [ ] ...'` → `printf '%s\n' "..."` ；`date +%s%3N` → `*1000`；SIGINT deferred → 改用 SIGTERM + trap INT TERM
  - `set -euo pipefail` 边界（3 个）：`count_checked` 双输出 → 变量捕获；`changed_files` 管道 exit 1 → `|| true`；`count_runs` 双输出 → 函数内提前判目录
  - JSON 正确性（1 个）：`_ralph_write_status` 第 10 参数 `"${10:-null}"` 改 `"${10:-}"` 防 JSON string `"null"`
  - 功能正确性（1 个）：空/全勾 TASKS.md 预检，主循环前直接 `done`
  - 第二轮额外清理：`api-error` 双写 log → 单写；`latest_run_dir` 空目录安全；删 session.sh 死代码（`fake_collect_session` / `fake_diagnose`）；删 integration-test.sh 未使用 `run_ralph` 函数；`update_meta_field` 尾逗号 bug → `-E` + capture group；删 `RALPH_BIN` 未使用变量
